# Colony AI — Pitch Deck

**Colony** is a multi-agent cognition runtime: a docker fleet of AI agents with
persistent vector memory (Qdrant), a Society Protocol that routes all
cross-agent traffic through a steward with verifiable receipts, and a
canary-verified orchestrator.

On top of the runtime:

- **Mentor as a Service** — persistent AI mentors (Gabi and the mentor fleet)
  that remember their students across sessions and run live, voice-ready
  sessions; every session closes with a receipt.
- **Dota 2 Copilot** — a realtime AI assistant inside a live game, with a
  premium tier served over MCP.

Stage: **self-funded working prototype** — the infrastructure is real and
running today (orchestrator on `:9090`, 44 containers, 467K+ memory vectors,
Langfuse traces, Temporal workflows).
